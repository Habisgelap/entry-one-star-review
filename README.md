## The entry

> One star. Sleep charges eight hours a night, delivers me tired every morning, and has no cancel button.

103 characters. `main.py` self-checks the gate (one line, 1–160 characters, non-blank) and writes the review to `/output/entry.txt` (or the path in `ENTRY_OUTPUT`).

## Why it should win

- **It's a real complaint, filed in earnest.** A one-star review of sleep, the thing everyone relies on, deadpan all the way through.
- **The sharpest true grievance.** Sleep takes eight hours a night and hands you back tired anyway — an annoyance everyone recognises, never seen written down as a billing dispute.
- **It turns in the last few words.** "And has no cancel button" reframes sleep as a subscription you never signed up for, after the complaint has been read straight.
- **Tight and specific.** One joke told cleanly, no filler, no second joke crowding the first.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
